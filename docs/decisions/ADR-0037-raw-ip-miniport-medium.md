# ADR-0037: Use the NDIS raw-IP medium for the virtual adapter

- **Status:** Accepted for source implementation; WDK and Windows validation pending
- **Date:** 2026-10-21
- **Context:** `IOCTL_BALANCIFY_INJECT_NBL` accepts raw IP packets, but the miniport and INF were advertising `NdisMedium802_3` / Ethernet. NDIS Ethernet receives include a link-layer header; treating raw IP bytes as Ethernet frames is an invalid interface contract. The adapter's intended path is IP-only, with no Ethernet/ARP emulation.
- **Decision:** Configure both `NDIS_MINIPORT_ADAPTER_GENERAL_ATTRIBUTES.MediaType` and INF `*MediaType` as `NdisMediumIP` (value 19), set the physical medium to unspecified, and use `LowerRange = "nolower"`. Do not expose Ethernet MAC-address OIDs or a nonzero MAC-address length. The maximum total packet size equals the configured IP MTU because the medium contributes no L2 header. Keep the receive packet filter initially disabled and accept only the supported filter bits via the existing OID handler.
- **Input validation:** `INJECT_NBL` treats input as one raw IPv4 or IPv6 packet, requires the version-specific minimum header, verifies the IP-declared total length exactly matches the supplied length, enforces the current MTU, and returns `STATUS_DEVICE_NOT_READY` while paused or while the receive packet filter is zero. The packet filter is checked again under the adapter lock immediately before tracking an indication so an OID change during allocation cannot bypass a disable. Counters are not incremented for these rejected paths. A WDK-independent C helper has boundary tests for valid IPv4/IPv6 packets, options/payload lengths, truncation, malformed declarations, unknown versions, and MTU limits.
- **Consequences:** The NDIS framing contract now matches the IOCTL payload. Ethernet-specific ARP, MAC learning, VLAN framing, and multicast link-layer semantics are not provided; they are outside the current IP-only miniport scope. The source has not been compiled with WDK or exercised on Windows, so the driver remains non-operational pending S2b validation.
- **References:** Microsoft WDK [`OID_GEN_MEDIA_SUPPORTED`](https://github.com/MicrosoftDocs/windows-driver-docs/blob/3aed2ca9f3624d431cba4e74b74e2e7284edf718/windows-driver-docs-pr/network/oid-gen-media-supported.md) defines `NdisMediumIP` as a generic medium for raw IP packets; [Media Extensibility in NDIS 6.20](https://github.com/MicrosoftDocs/windows-driver-docs/blob/3aed2ca9f3624d431cba4e74b74e2e7284edf718/windows-driver-docs-pr/network/media-extensibility-in-ndis-6-20.md) describes raw-IP support.
